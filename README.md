# RCDS × MetaMap-ML Quantum Research Prototype

A local research dashboard that connects simulated or Arduino-streamed colorimetric assay data to a mechanistic pathway model, synthetic machine-learning predictors, and CUDA-Q demonstrations.

## Data and computation flow

1. **Arduino Uno / RCDS sensors** acquire color channels, pH and temperature and send CSV over USB serial. The Uno is an acquisition controller; it does not run the Python, ML or quantum workloads.
2. **Sensor conversion** applies blank correction and Beer–Lambert conversion to estimate a nitrite/nitrosamine concentration.
3. **MetaMap pathway model** estimates pathway fluxes, metabolite pools, UGT demand and adduct susceptibility features under adjustable enzyme efficiencies.
4. **CUDA-Q metabolic feature circuit** encodes carcinogen load, GALT activity, ATP ratio and UDP-glucuronate pool into a four-qubit circuit. The resulting observable is a prototype score, not a clinically validated probability.

The GHZ scaling benchmark and H₂ VQE are complementary quantum-computing demonstrations. They do not directly measure carcinogens or feed their results into the RCDS score.

## Project files

- `rcds_dashboard.py` — dark Streamlit dashboard with sensor controls, pathway network, synthetic ML predictors, guided CUDA-Q lab and Arduino wiring view.
- `rcds_metamap_engine.py` — sensor conversion and mechanistic pathway / stress calculations.
- `cudaq_rcds_sim.py` — automatic CUDA-Q target selection, GHZ statevector benchmark, H₂ STO-3G Jordan–Wigner Hamiltonian and UCCSD VQE sweep.
- `rcds_arduino_uno.ino` — Arduino Uno firmware for the RGB sensor, pH interface and temperature probe.
- `HARDWARE_GUIDE.md` — bill of materials, wiring, enclosure and calibration notes.
- `ghz_scaling.png`, `vqe_pes_curve.png` — example plots generated by the quantum simulation script.

## Environment

Use Python 3.11+ and install CUDA-Q 0.17.0 plus the packages listed in `requirements.txt`. PySCF is needed for the STO-3G H₂ integral generation. The CUDA-Q `nvidia` target requires a compatible NVIDIA GPU/runtime; on CPU-only hosts, the code selects `qpp-cpu` and labels the cuStateVec curve as a projection.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On systems where CUDA-Q needs an NVIDIA package index or a supported CUDA stack, follow the official CUDA-Q installation instructions for that machine before installing the remaining requirements.

## Run

```bash
python cudaq_rcds_sim.py
streamlit run rcds_dashboard.py
```

The dashboard defaults to simulated sensor input. To use hardware, connect the Uno, select **Live Arduino Uno Serial Port**, choose its serial device and request a sample.

## Scope and limitations

This is a software and hardware-integration prototype. Assay conversion factors, pathway kinetics, synthetic training data, quantum feature score and Arduino wiring must be validated against the actual reagents, sensor modules and calibration standards before experimental use. The synthetic ML model is not trained on clinical data. The tool is not a diagnostic device and does not establish that an assay detects a specific carcinogen in real samples.
